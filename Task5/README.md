Основная точка входа - запрос `client(id: ID!)`, через который можно получить как базовые данные, так и связанные: `documents` и `relatives`. Это избавляет от необходимости слать несколько REST-запросов подряд.

Связи (`documents`, `relatives`) подтягиваются только если запрошены - GraphQL сам оптимизирует объём данных под конкретный сценарий.

Гибкость запроса - потребители сами выбирают, какие поля нужны.
Например, веб-клиент может запросить только `id`, `name` и `documents { type number }`, а `core-app` - дополнительно `relatives { relationType name }`.
